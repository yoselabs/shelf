# Gate decisions from the task-loop migration (shelf-v376, shelf-luti)

* **One owner per fact** (shelf-v376): `packages/blueprint/src/blueprint/owners.toml` maps each pinned fact to the one file that holds it; a second copy fails `stack.one-owner` and the message names the owner. `.python-version` owns the Python version (X.Y or X.Y.Z, pre-release tags allowed); `requires-python` stays a range; mise.toml, `.tool-versions` and `[tool.uv] python` must not repeat it. `mise.toml` owns the uv version; `required-version` is a `>=` floor, an exact one is a copy. `global.json` owns the .NET SDK.
* **Coverage floor vs the selection-based `test`** (shelf-luti a): the floor lives in `test-all`, the test step of `check-all` (the release gate). `test` runs only what the change reaches, so it cannot meet a whole-repo floor and does not try. The rendered base now has `check-all`, the python part `test-all` (`--cov-fail-under=65`); the profile's floor row already reads `check-all`.
* **Preset copy without shelf-only paths** (b): the packaged snapshot (`preset.toml`) carries rule lists, linter versions and size caps only; a test fails if `packages/`, `tools/` or `per-file-ignores` appear in it. Copying it by `init` is part of shelf-u7f4.
* **Bare `just` from mise** (c): a python repo with `just` pinned in mise.toml (no `rust-just`) passes `stack.tool-pins` and `gate.runner`; tested. The gate's own steps still say `uv run`, because `uv` is the stack's tool, not the runner's.
* **Internal entry scripts** (d): a bare `sys.argv` read no longer makes a script a command for `cli-help-tested`; an `ArgumentParser`, click or typer does. The day a hook script grows a parser it needs the help test (ADR 0025's intent holds for anything with a usage). The folder-scoped override bug is shelf-3jh, not touched here.
