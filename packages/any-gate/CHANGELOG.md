# any-gate — changelog

AI-facing only: one line per contract-shape change, arrow notation.

## 0.8.0

- `any_gate test` strips `GATE_NOTICE_FD` from its runner's environment (`run_runner(..., env=)`): the number is a descriptor of the gate's own process, and in the runner's tree it named an xdist worker's pipe to its controller; a notice written there stalled the run until the idle limit (600 s).
- A gate that judged nothing records no green: `any_gate unjudged --reason R` (`GateState.unjudged`, `unjudged_reason`, marker `gate-unjudged` in the git dir, `state.UNJUDGED`) makes `passed` record nothing and say why; `start` clears it. `any_gate test` with an empty plan marks it (0 suites planned although the gate said run). A step that passes on the network's word (offline `dep-audit`, `tag-check` on local tags) marks it too.
- `steps` takes the gate lease first, then decides what to skip (`_decide`): files edited during the queue are seen.
- `state.working_tree(repo, env)` = the temp-index tree id `working_key` is built from (`working_key` unchanged).
- Gate output, log-driven and terse (`steps.render`, `steps.header`, `any_gate.note`): header `gate base=<sha7|NONE> files=N|all: <steps>`; no pre-run `run X:` lines; after the steps one line per step, `ok|WARN|FAIL|stop NAME Ns [⚠ over Bs] | <why it ran> | <step note> [| log PATH]`, a skipped step as its `skipped NAME: why` line (prefix contract kept), footer `gate ok|FAIL a b | 4 ok 1 skipped | 41s` (replaces `gate: a 3s · b 5s -- total` and `gate: failed:`). `note(text)` prints `gate-note: text` into the step's log; the last one is shown; a note starting `0 ` on a step the gate said to run is WARN. A failure shows its first 10 and last 10 log lines (each cut at 200 chars) and `log: <git-dir>/gate-logs/<step>.log` (kept, overwritten per run; `Step.log_path`). `FAILED_LOG_LINES` is now 20. The header asks git again (base + change set: 4 calls) because `inputs.explain` does not hand its change set on.

- Gate lease (review fixes): `hold` waits for a live, fresh holder instead of running anyway at `--gate-wait`/`$GATE_WAIT` (now the re-judging interval, 900 s); it runs anyway only when the holder's pid is gone, unnamed, or older than `$GATE_STALE_AFTER` (7200 s), and says which. `ANY_GATE_LEASED` holds the owning gate's pid and waives the lease only while that pid lives (a daemon a step started no longer waives later gates; a bare `1` waives nothing). The first wait line is also written to `/dev/tty` when stderr is captured (a git hook) and says `a gate already runs in this repo` when the holder is this repo's. Lease root: `gate_lease.default_root(env)` = `$GATE_LEASE_ROOT`, `$XDG_CACHE_HOME/gate-leases`, else the account's home from the password database (not `$HOME`); an unusable root warns and runs without a slot.

- `any_gate steps` holds one machine-wide gate slot (`gate_lease.hold`, lease `gate`, `--gate-slots`/`$GATE_SLOTS` default 1, 0 = off): a second gate prints one `gate: waiting for a gate slot, held by ... (pid N, held M min)` line (repeated every 5 min) and waits, at most `--gate-wait`/`$GATE_WAIT` 900 s, then runs anyway and says so. Steps inherit `ANY_GATE_LEASED=1` so a gate inside a gate never waits on its parent. `wait_message(wait, what=)` and `REPEAT_WAIT_NOTICE` moved to `any_gate.gate_lease` (still importable from `any_gate.cli`). (shelf-7aqn)
- Gate output says why (log-driven): `inputs.explain(repo, names, recorded) -> (skips, runs)`; `steps` prints `run NAME: N changed (GLOBS)` / `run NAME: no gate passed this tree | gate definition changed | changed files unknown | declares no inputs | --all` before the steps, and `skipped NAME: none of GLOBS changed` after; `run_and_report(..., why=)`. `any_gate test` ends with `test: ran N of M suite(s), K unchanged since they passed -- Ss`. `inputs.unaffected` unchanged in shape, its text now names the globs.

- 0.6.0: `inputs.declared(repo)` = `.blueprint/step-inputs.toml` (blueprint's defaults) widened by the repo's `gate-inputs.toml`; a `[narrow]` step takes the repo's list alone; a change to the defaults file runs every step; `inputs.DEFAULTS`.

- 0.5.0: SIGTERM/SIGHUP stop every step tree; `Step.stopped` replaces exit 125 as "stopped by the gate"; a crashed step thread is a failed step (70); `GATE_FAIL_FAST`; `inputs.unaffected(repo, names, recorded)` runs everything on an empty change set no gate passed; a step named twice is refused. Contract otherwise unchanged.
