# Semantic nonsealed Codex launches

Task shelf-evlp; candidate any-agent0.4.0, not delivery. The actual factory consumer
cannot construct a working fresh launch from existing typed options: released0.3.0
required the caller to build complete vendor argv in LaunchInputs.cli. Root,
independent review and Astra approved a hard cut to the owning harness builder.
No retained production nonsealed caller needing raw replacement was identified;
anyllm uses sealed mode. Historical delegate is not an adopted successor consumer.

Remove cli and resume's extraction of its skip-Git flag. Existing launch_spec now
builds fresh/resume argv from semantic fields, preserving access/isolation, schema,
output, prompt, process cwd/environment and explicit session. No raw fallback,
second builder/facade or new skip-Git option. Old arbitrary command customization
is deliberately lost; existing release tags remain immutable. Factory code/pins
remain unchanged until owning delivery is verified.
