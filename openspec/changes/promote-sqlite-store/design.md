## Contract and boundaries

Extract `factoryconnections`, the generic portions of `factorydb`, and
`factorymigrate` from the read-only copies in `docs/review`. The package contains
no application table, column or domain SQL. Schema and migration SQL are supplied
by the caller. One source module owns each requested concept; Store composes them.

The only SQL column policy is the extracted CAS contract's `rev` field. Schema
creation deliberately retains statement splitting on semicolons and forbids
triggers and embedded semicolons. Migration steps must not end transactions.

## Extraction choices

- Preserve source opener failures: filesystem/WAL/storage failures return None;
  only SchemaError propagates. The request also asks for a WAL-unavailable raise
  test: that assertion is at the internal configuration boundary, with the public
  refusal tested separately. This discrepancy remains explicit for owner review.
- Schema checks have no counterpart in the provided factory sources. Treat them
  as extra integrity SQL queries, evaluated with quick_check and requiring exactly
  one `ok` row. Document and test this assumption rather than introduce domain SQL.
- Only older configured versions are eligible for quarantine; a newer schema is
  refused even if included in quarantine_versions. The lock name appends
  `.schema.lock` to the complete path, as requested.
- Store owns its own shared writers and check cache. Standalone opens share a
  module-level integrity cache. Cache identities include PID, path, device and
  inode. Filesystem cache resets on fork; shared writer locks are replaced on fork.
- Use thread barriers for concurrent creation, upgrades and quarantine. Simulate
  PID changes for fork ownership contracts; never spawn a process in these tests.

## Validation boundary

Tests are written before implementation but remain unexecuted: the owner explicitly
forbids uv, just, pytest, git and bd in this session. No tool versions or lockfile
are generated by hand. Only handwritten testpath and import-linter lists change;
the uv workspace already discovers packages through `packages/*`.
