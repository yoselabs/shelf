# Promote any-recorded-fixture

## Why
Task-loop records real model-call exchanges per case and replays them as a golden.

## What Changes
Add a stdlib-only candidate package matching any-mailbox layout, register its boundaries and tests,
and publish a catalog manifest, delivery ledger entry and consumer retention claim.

## Capabilities
New capability: recorded-fixture, JSON case recording and text golden replay.

## Impact
Root package registrations only; lockfile and generated indexes are left for the owner to regenerate.
